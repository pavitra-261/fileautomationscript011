#FILE AUTOMATION SCRIPT

## Description

This Python project automatically organizes files into folders based on their file types.

## Features

* Sorts files by extension
* Creates folders automatically
* Moves files to the correct folders
* Generates logs for tracking file movements

## Technologies Used

* Python
* os module
* shutil module
* logging module

## How to Run

1. Clone the repository
2. Open the project folder
3. Run the Python file

bash
python automation.py


## Example

Before:
Downloads/

* image.jpg
* document.pdf
* song.mp3

After:
Downloads/

* Images/vk1.jpg
* Documents/report.pdf
* Audio/song.mp3
